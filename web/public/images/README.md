# Image library — `web/public/images/`

Every file here is served from `/images/…`. Folders match the experience slugs in
[`web/src/content/experiences.ts`](../../src/content/experiences.ts) so a page can find its
photos without a lookup table.

| Folder | Maps to | Count |
|---|---|---|
| `fleet/` | the cars themselves — hero, about, generic brand imagery | 12 |
| `rural-saloia/` | experience slug `rural-saloia` | 8 |
| `obidos-medieval-villages/` | experience slug `obidos-medieval-villages` | 13 |
| `tasco-galapito/` | experience slug `tasco-galapito` | 24 |
| `manzwine/` | experience slug `manzwine` | 3 |
| `ramilo-wines/` | experience slug `ramilo-wines` | 4 |
| `weddings/` | `/casamentos` | 17 |
| `testimonials/` | guest testimonial portraits, named after the guests | 3 |
| `wedding-awards/` | casamentos.pt award badges, one per year | 5 |

Naming rule: lowercase kebab-case, describing **what is in the frame**, not the camera's
filename. Vehicle shots lead with the car (`citroen-2cv-…`, `renault-4-…`, `fiat-600-…`,
`vw-t3-van-…`) so they sort together.

## Root files
Only two remain, and both stay put on purpose:

- **`logo.png`** — brand mark. `lib/email-layout.ts` embeds it as an absolute URL
  (`${site.domain}/images/logo.png`), so every transactional email already sent points here.
  Moving it would break the logo in that mail.
- **`video.mp4`** — the homepage hero video, not a photograph.

Every other root image moved into the folders above; all `src/` references were updated.
